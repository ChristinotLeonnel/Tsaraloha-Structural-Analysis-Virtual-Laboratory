SECTION 2 : PORTEE, PUBLIC CIBLE ET PRE-REQUIS (IEEE Std 1063 §5.3 - §5.4)
--------------------------------------------------------------------------------
* Portee : Ce document constitue la reference exhaustive des accelerateurs
  clavier, raccourcis de navigation 3D et commandes console du logiciel TSA.
* Public Cible : Ingenieurs civils, projeteurs structures, calculateurs et
  developpeurs integrant le systeme de commandes TSA.
* Pre-requis : Poste de travail Windows x64, clavier standard (avec pave
  numerique recommande) et souris 3 boutons avec molette pour la vue 3D.

SECTION 3 : CONVENTIONS ET NOTATIONS TYPOGRAPHIQUES (IEEE Std 1063 §5.5)
--------------------------------------------------------------------------------
Legende des touches :
  Ctrl     = Touche Controle (Cmd sous macOS si porte)
  Shift    = Touche Majuscule
  Alt      = Touche Alternative
  Num+<N>  = Pavé numerique (Keypad 0 a 9)
  Echap    = Touche Echappement (Escape - annulation / deselection)
  Suppr    = Touche Suppression (Delete)
  Home     = Touche Origine (Reinitialisation vue accueil)
  F1-F12   = Touches de fonctions standardisees (F1: Aide, F3: OSNAP, F5: Solve, F7: Grille, F11: Plein ecran)
  [aucun]  = Fonction accessible via Menu, Ruban ou Console sans raccourci direct

================================================================================
  1. FICHIER
================================================================================

  Ctrl+N              Nouveau Projet
  Ctrl+O              Ouvrir un projet (.tsa)
  Ctrl+S              Enregistrer
  Ctrl+Shift+S        Enregistrer sous...
  Alt+F4              Quitter TSA

================================================================================
  2. EDITION
================================================================================

  Ctrl+Z              Annuler (Undo)
  Ctrl+Y              Retablir (Redo)
  Ctrl+Shift+Z        Retablir (Redo - alternatif)
  Ctrl+C              Copier les elements selectionnes
  Ctrl+V              Coller les elements du presse-papier
  Suppr               Supprimer les elements selectionnes
  Ctrl+A              Tout Selectionner
  Ctrl+Alt+I          Inverser la selection
  Echap               Mode Selection / Effacer la selection

================================================================================
  3. CREATION D'ELEMENTS (Modes de dessin 3D)
================================================================================

  N                   Mode Dessin - Noeud structural
  B                   Mode Dessin - Poutre
  C                   Mode Dessin - Poteau
  Alt+C               Mode Dessin - Cable / Hauban
  L                   Mode Dessin - Dalle
  W                   Mode Dessin - Voile
  [aucun]             Mode Dessin - Fondation
  [aucun]             Mode Dessin - Barre generique
  [aucun]             Mode Dessin - Treillis

================================================================================
  4. MODIFICATION / TRANSFORMATIONS 3D
================================================================================

  M                   Deplacer point-a-point (Move 3D interactif)
  Ctrl+Shift+M        Translation numerique par dialogue (dX, dY, dZ)
  Ctrl+D              Copie 3D / Copie numerique parametrique
  Ctrl+R              Rotation 3D (interactive)
  [aucun]             Deplacer vers l'Origine (0,0,0)
  [aucun]             Symetrie / copie miroir par rapport a un plan X, Y ou Z (console : MIRROR, MI)
  [aucun]             Diviser les poutres/poteaux selectionnes en N troncons (console : SPLIT, DIVIDE)
  [aucun]             Fusionner les noeuds confondus a tolerance pres (console : MERGE, FUSION)

================================================================================
  5. AFFICHAGE - NAVIGATION 3D
================================================================================

  F                   Tout Ajuster (Fit All)
  Shift+F             Cadrer sur la Selection
  +                   Zoom Avant
  -                   Zoom Arriere
  [aucun]             Zoom Fenetre (selection rectangulaire)
  Home                Vue Initiale (Home 3D)
  R                   Reinitialiser la Vue (Reset View)
  Alt+Left            Vue Precedente (historique camera)
  Alt+Right           Vue Suivante (historique camera)

================================================================================
  6. VUES PREDEFINIES (Orientations de camera)
================================================================================

  Num7                Vue de Dessus  (+Z)
  Ctrl+Num7           Vue de Dessous (-Z)
  Num1                Vue de Face    (+Y)
  Ctrl+Num1           Vue Arriere    (-Y)
  Num3                Vue Gauche     (-X)
  Ctrl+Num3           Vue Droite     (+X)
  Num5                Vue 3D Isometrique
  [aucun]             Plan XY (vue d'etage)
  [aucun]             Plan XZ (facade / elevation)
  [aucun]             Plan YZ (pignon / coupe laterale)

================================================================================
  7. PLAN DE TRAVAIL (WorkPlane)
================================================================================

  Alt+Z               Plan de Travail XY (horizontal)
  Alt+Y               Plan de Travail XZ (vertical frontal)
  Alt+X               Plan de Travail YZ (vertical lateral)
  [aucun]             Plan de Travail Etage (niveau actif)

================================================================================
  8. GRILLE & NIVEAUX
================================================================================

  G                   Afficher / Masquer la Grille 3D
  F7                  Afficher / Masquer la Grille (alternatif)
  S                   Activer / Desactiver le Magnetisme Grille (Snap)
  F3                  Activer / Desactiver l'Accrochage Objets (OSNAP)
  Ctrl+L              Gestionnaire d'Etages et Niveaux
  [aucun]             Gestionnaire de Grilles
  [aucun]             Afficher Plans d'Etages
  [aucun]             Afficher Libelles d'Axes
  [aucun]             Afficher Regles Graduees

================================================================================
  9. PROPRIETES & BIBLIOTHEQUES
================================================================================

  P                   Panneau Proprietes (toggle visibilite)
  [aucun]             Catalogue Profiles (sections TSALib)
  [aucun]             Catalogue Materiaux (Eurocodes / ASTM)
  [aucun]             Catalogue Cables (torons et cables clos)
  [aucun]             Gestionnaire d'Extensions (.tsalib)

================================================================================
  10. CHARGES
================================================================================

  [aucun]             Charge Ponctuelle (force sur noeud)
  [aucun]             Charge Repartie (lineique sur barre)
  [aucun]             Moment Flechissant
  [aucun]             Action Sismique (spectre EC8)

================================================================================
  11. ANALYSE & CALCUL
================================================================================

  F5                  Calcul Statique ([K]{u}={F})
  [aucun]             Generer le Maillage EF 1D/2D
  [aucun]             Analyse Modale (frequences et modes propres)

================================================================================
  12. RESULTATS
================================================================================

  [aucun]             Deplacements / Deforme
  [aucun]             Efforts Internes (moments, tranchants)
  [aucun]             Contraintes (Von Mises)

================================================================================
  13. INTERFACE & THEME
================================================================================

  Ctrl+T              Basculer Theme (Sombre / Clair)
  F11                 Mode Plein Ecran
  [aucun]             Afficher / Masquer Plan de Coupe 3D
  [aucun]             Systeme de Coordonnees

================================================================================
  14. AIDE
================================================================================

  F1                  Afficher la liste des raccourcis clavier
  [aucun]             Aide generale
  [aucun]             A Propos de TSA

================================================================================
  15. ISOLATION 3D
================================================================================

  I                   Isoler la Selection (masque le reste)
  Alt+I               Isoler par Type (meme type que la selection)
  Alt+W               Isoler sur le Plan de Travail
  H                   Masquer la Selection
  [aucun]             Inverser l'Isolation
  Ctrl+H              Isolation Precedente (annule la derniere isolation)
  Alt+H               Tout Afficher (fin de l'isolation)

================================================================================
  RESUME RAPIDE - RACCOURCIS LES PLUS UTILES
================================================================================

  Fichier    : Ctrl+N  Ctrl+O  Ctrl+S  Ctrl+Shift+S
  Edition    : Ctrl+Z  Ctrl+Y  Ctrl+C  Ctrl+V  Suppr  Ctrl+A
  Dessin     : N (noeud)  B (poutre)  C (poteau)  Alt+C (cable)
               L (dalle)  W (voile)
  Modif 3D   : M (deplacer)  Ctrl+D (copier)  Ctrl+R (rotation)
  Vue        : F (fit)  Shift+F (cadrer)  +/-  Home  R (reset)  Alt+Left/Right
  Vues campi : Num1/3/5/7 (face/gauche/iso/dessus)
  Grille     : G (grille)  F7 (grille alt.)  S (snap)  F3 (osnap)  Ctrl+L (niveaux)
  Calcul     : F5 (calcul statique)
  Theme      : Ctrl+T
  Plein ecran: F11
  Proprietes : P
  Isolation  : I (isoler)  H (masquer)  Alt+H (tout afficher)  Ctrl+H (annuler)
               Alt+I (type)  Alt+W (plan)  Ctrl+I (coupe)  Ctrl+Shift+I (projection)
  Undo/Redo  : Ctrl+Z / Ctrl+Y (ou Ctrl+Shift+Z)
